## Desenvolvimento

Prefere trabalhar localmente? Você precisará do Node.js e do npm — [instale usando o nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <url-deste-repositorio>
cd <nome-do-repositorio>
npm i
npm run dev
```
